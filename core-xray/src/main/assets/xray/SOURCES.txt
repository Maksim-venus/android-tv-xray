Passwall TV — bundled routing assets
====================================

APK defaults (copied to filesDir/xray/ on first run). Invalid / truncated
files are replaced — we no longer keep a broken “last-good” geosite.dat.

  geoip.dat
    Source: Loyalsoldier/geoip  geoip-only-cn-private.dat
    Tags:   cn, private
    Size:   ~134KB. Enough for geoip:cn / geoip:private → direct.

  geosite.dat
    Source: Loyalsoldier/v2ray-rules-dat  official geosite.dat
    Must contain `cn` (and geolocation-!cn, category-ads-all).
    Fetched by scripts/fetch-geo-assets.sh and checked by
    scripts/validate-geodata.py. Do NOT use generate-geosite.py.

  direct-list.txt
    Source: Loyalsoldier/v2ray-rules-dat  direct-list.txt

  cn-cidr.txt
    Source: 17mon/china_ip_list
    Used only if geoip.dat is unusable.

If geosite.dat still fails Xray load at runtime, the VPN start path
retries with IP-only rules (geoip:cn / cn-cidr) and writes a Chinese
error to the in-app log.

7-day remote refresh (after a successful proxy start):

  geoip.dat / geosite.dat / direct-list.txt
    jsDelivr → Fastly → GitHub (Loyalsoldier/v2ray-rules-dat).
    geosite downloads smaller than 100KB are rejected.
